# Student Expense Tracker - 12 Modules

The source files are named Q01.cpp through Q12.cpp and correspond to the 12 modules in the project brief.

Compile an individual program with C++17, for example:

```sh
g++ -std=c++17 Q01.cpp -o Q01
./Q01
```

Q01 and Q02 share `users.txt`. Expense modules share `expenses.txt` with rows formatted as `date|category|amount|description`; budget modules use `budgets.txt`. Run programs from the same folder to share these files. Category and description inputs are single words in these introductory examples. Registration stores passwords as plain text; use a sample password, not a real one.
